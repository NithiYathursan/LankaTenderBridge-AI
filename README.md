# LankaTenderBridge AI 🇱🇰

An Intelligent Multilingual Government Tender Discovery
and Business Opportunity Matching System for Sri Lanka.

## Project Overview

LankaTenderBridge AI aims to collect publicly available
Sri Lankan government tender notices and use Machine
Learning and Neural Networks to identify relevant
business opportunities.

## Project Objectives

1. Collect public tender notices from permitted sources.
2. Extract structured information from HTML and PDF.
3. Classify tender documents using Machine Learning.
4. Apply Neural Networks for semantic understanding.
5. Match business profiles with relevant tenders.
6. Detect tender amendments and deadline changes.
7. Develop an interactive AI-powered application.

## Data Policy

Only publicly accessible information will be collected
from sources that permit automated access.

Source attribution, request limits, and website terms
will be respected.

## Disclaimer

This is a research and decision-support prototype.
Users should verify tender information using official
government notices.
